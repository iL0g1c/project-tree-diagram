0.4.0-beta
=============================
FEATURES
--------
/patrolling manual_log (allows for manually logging a patrol)
/patrolling patrol-delete (allows for deleting a patrol)
/patrolling patrol-report (allows for getting all patrols after a specified date)
/patrolling online (Gets all of your forces online pilots)
/patrolling kill (allows for logging a kill)

CHANGES
-------
Fixed async warnings in backend server.
Centralized error handler in server backend.
Event ID now displays in patrol logs.
Deleted unused /patrolling patrol-report-role command.
Deleted unused /patrolling inactive command.
